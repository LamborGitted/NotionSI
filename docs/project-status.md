| 原生聊天 | 经典 transcript 与正式回复保存、新版 personal Agent、分页与订阅、图片附件与多模态转换、进程内模型历史 | 经典回复留存修复尚待桌面复验；模型历史与新版 Agent 会话仍在进程内；图片单张 5 MiB，保留历史最多 10 张、10 MiB，实际桌面上传待验证 |
| 笔记上下文 | 无选区时读取当前页，保留链接与页面引用，自动加载本轮引用的 Notion 页面；每轮刷新 | 需开启 `native` 工具；最多 5 页、40000 字符、15 秒；外部网页仅保留地址；选区模式沿用选区边界 |

| 编辑器 AI | 改写、语法、缩短、扩写、摘要、续写、解释、自定义要求；原生预览、接受与撤销 | 连续文本选区；图片、数据库、嵌套原始选区和空光标写整页未适配 |
| 格式与边界 | 编辑器输出支持标题、列表、待办、表格、代码与行内格式；过期修改与越界写入保护 | 整页工具仍使用较小 Markdown 子集；撤销快照仅存在进程内 |
| 配置与日志 | 交互终端配置、LocalAppData 用户文件、兼容项目环境文件、系统提示词、隐藏 Key 输入、流式终端正文或仅进度 | 默认终端正文可能引用页面内容，可用 `NOTIONSI_LOG_CONTENT=0` 关闭 |

## 发布整理

- 保留 `src/`、`test/`、`scripts/`、文档、锁文件与无密钥配置示例。
- 忽略 `.env.local`、本地提示词、`.local/`、依赖目录，以及包含提取应用文件和原始证据的整个 `research/`。

- 提供 GitHub Actions：在 Node.js 24 的 Ubuntu、Windows 环境执行 `npm ci` 和 `npm test`。远端运行结果须以 Actions 实际完成记录为准。
- 已提供标签触发的自动打包与 Release 发布、下载校验及升级说明，见 [版本发布指南](releases.md)。npm 分发或打包安装器按需要另做，不必先去掉 `private: true`。
- `package.json` 的 `private: true` 防止误发布到 npm，不影响上传 GitHub。

GitHub 仓库是否已创建或推送，以远端仓库和 Git 状态为准；这份文档记录准备内容，不作为发布成功证明。
