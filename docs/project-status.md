# 开发状态与发布准备

整理日期：2026-10-27。当前包版本为 `0.2.0`，定位为可运行的实验性原型。已验证环境为 Windows、Scoop Notion 7.40.1，以及当时加载的 Notion 网页构建；不保证其他构建兼容。

## 已完成

| 模块 | 当前能力 | 主要限制 |
| --- | --- | --- |
| 启动与接管 | 查找 Scoop Notion、复用本机 CDP、临时注入及退出时移除 fetch 钩子 | 其他安装位置需传 `--notion`；不会强制退出已有后台进程 |
| 模型对话 | mock 固定回答、智谱标准 API / Coding Plan CN、SSE 流式输出、取消与错误终态 | 两个端点显式选择，不自动回退；模型可用性取决于用户账户 |
| 原生聊天 | 经典 transcript、新版 personal Agent、分页与订阅、进程内历史 | 会话历史未持久化，适合新建测试对话 |
| 页面工具 | 标题搜索、读取、创建、基础 Markdown 更新、移入回收站 | 未知或嵌套内容拒绝整页替换，无附件或连接器搜索 |
| 数据库与待办 | 基础列、建行、视图查询、聊天内本地任务清单 | 不支持 SQL、JOIN；待办不等于 Notion 持久化任务数据库 |
| 编辑器 AI | 改写、语法、缩短、扩写、摘要、续写、解释、自定义要求；原生预览、接受与撤销 | 连续文本选区；图片、数据库、嵌套原始选区和空光标写整页未适配 |
| 格式与边界 | 编辑器输出支持标题、列表、待办、表格、代码与行内格式；过期修改与越界写入保护 | 整页工具仍使用较小 Markdown 子集；撤销快照仅存在进程内 |
| 配置与日志 | 本地环境文件、系统提示词、密钥隐藏、流式终端正文或仅进度 | 默认终端正文可能引用页面内容，可用 `NOTIONSI_LOG_CONTENT=0` 关闭 |

## 发布整理

- 保留 `src/`、`test/`、`scripts/`、文档、锁文件与无密钥配置示例。
- 忽略 `.env.local`、本地提示词、`.local/`、依赖目录，以及包含提取应用文件和原始证据的整个 `research/`。
- README 增加快速开始、实验阶段说明与状态入口；公开文档使用独立协议概览，不依赖本地研究文件。
- 提供 GitHub Actions：在 Node.js 24 的 Ubuntu、Windows 环境执行 `npm ci` 和 `npm test`。远端运行结果须以 Actions 实际完成记录为准。
- `package.json` 的 `private: true` 防止误发布到 npm，不影响上传 GitHub。

GitHub 仓库是否已创建或推送，以远端仓库和 Git 状态为准；这份文档记录准备内容，不作为发布成功证明。
